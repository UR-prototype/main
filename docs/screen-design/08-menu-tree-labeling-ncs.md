# 메뉴 트리 (라벨링 · NCS 평가 반영)

## 업무 구분

```text
외부 전달
  · 객체 라벨링 · 포즈 라벨링  → 별도 진행 후 결과 인수
  · UR: 영상 + 메타정보 입력 창

내부 라벨링 (+ AI 보조)
  · 타임라인 이상행동 라벨
  · 결과 조형물 문제점(좌표) 라벨
  · UR: 영상·조형물 등록 / 타임라인 작업 / 조형물 좌표 작업

결과물 분석
  · 숙련도 = AI 점수 단독이 아님
  · NCS 기반 프로세스 + 전문가 의견
```

## 사이드바 (상위) · 본문 탭 (하위)

```text
대시보드                 /
등록                     /register
  ├─ 영상·정보           /register/          ← 외부 객체·포즈 인수 포함
  └─ 조형물 이미지       /register/product/
라벨링                   /labeling
  ├─ 타임라인            /labeling/          ← 재생 시간 이상행동
  └─ 조형물 좌표         /labeling/product/
숙련도 평가              /evaluation         ← NCS · 전문가
작업 현황                /work
  ├─ 전체 영상
  ├─ 진행·검토
  └─ 실패
기술자                   /workers
  ├─ 목록
  └─ 비교
```

기존 분석 결과(`/analysis/...`)·평가서(`/reports/...`)는 숙련도 평가·작업 현황에서 연결.
