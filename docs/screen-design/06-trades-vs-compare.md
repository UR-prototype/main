# 직종 탭 vs 비교 탭

## 결론

**별도 「직종」 페이지는 필요 없음.** `비교`에 흡수한다.

## 이유

| | 직종 탭 (구) | 비교 탭 |
|--|-------------|--------|
| 직종 단위 보기 | 카드 목록 | 꺾은선 + 필터 |
| 인력 비교 | 이름·점수만 | 지표 표 |
| 관련 영상 | 있음 | 직종 선택 시 표시로 이전 |
| 지원 범위 | 배지·피처 | 동일 정보 흡수 |

두 탭이 **같은 축(직종 → 사람 → 영상)** 을 반복해서, 탭만 늘리고 밀도는 떨어졌다.

## 현재 IA

```text
기술자
  · 목록
  · 비교   ← 직종 그래프 + (선택 시) 지원·관련영상 + 인력 표
```
