# 02 · v0.2 실사용 IA · 메뉴바

> 목표: **진짜 쓰는 콘솔**처럼 보이게. 시연 1~5는 글로벌 메뉴에서 제거.  
> 역할: 개발 브리프 기준 `company` · `evaluator` · `admin`

---

## 1. 정보 구조 (한 장)

```text
로그인
 └─ 앱 셸
      ├─ [글로벌 사이드바]  업무 모듈만
      ├─ [상단] 페이지 타이틀 · 브레드크럼 · (역할/계정)
      └─ [본문]
           ├─ 목록
           └─ 상세 (서브탭 · 분석 하위 뷰)
```

**Drill-down (시연 하드코딩 대신)**

```text
대시보드
  → 작업자 목록 → 작업자 상세 → 평가 건/영상
       → 분석 결과 (하위: 종합 / Pose / 시간 / 반복 / 결과물)
            → 검토·승인
                 → 평가서 · 매칭 참고
```

## 2. 글로벌 사이드바 (제안)

그룹은 **업무 목적** 기준. 라벨은 한국어 우선.

### 공통 골격

```text
UR Connection
────────────────
현황
  · 대시보드

등록·관리
  · 작업자
  · 평가 건 / 영상

분석·검토
  · 분석 큐 / 상태
  · 검토 대기          ← evaluator 강조

결과·활용
  · 평가서
  · 인력 비교
  · 직종별 현황

운영                     ← admin (+ company 일부)
  · 실패·재처리
  · 평가 기준 (직종·배점)   ※ Phase 후반
  · 사용자·권한             ※ Phase 후반

────────────────
로그아웃
```

| 평가 건 / 영상 | ● | ○ | ● |

○ = 조회 위주 / 제한 · ● = 주 사용 · — = 숨김

## 5. 대시보드 역할별 첫 화면

| 역할 | 첫 화면 초점 | 주 CTA |
|------|--------------|--------|

## 6. 분석 상세 서브내비 (Pose 위치)

```text
분석 결과
  ├─ 종합          /analysis/[id]
  ├─ 자세(Pose)    /analysis/[id]/pose
  ├─ 작업 시간     /analysis/[id]/time
  ├─ 반복 패턴     /analysis/[id]/repetition
  ├─ 결과물        /analysis/[id]/product
  └─ 검토·승인     /analysis/[id]/review   (또는 /reviews/[id])
```

사이드바에 Pose를 빼는 것이 v0.2 메뉴 정리의 **핵심**.

## 7. 브레드크럼 규칙

시연 `현황 / 작업자 / AI 분석 / …` 대신:

```text
작업자  >  DO TIEN DUC  >  V-101 분석  >  자세
평가 건  >  V-101  >  검토
```

「다음 · Pose」식 시연 CTA는 제거하고,  
업무 CTA는 **검토하기 / 평가서 보기 / 재분석 요청** 등으로 통일.
