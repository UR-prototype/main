# IA 결정 (v0.2 구현 반영)

## 병합·제거 근거

| 기존 | 판단 | 처리 |
|------|------|------|
| 작업 영상 | 평가 건(영상) 마스터 목록 | **작업·분석 → 전체 영상** |
| 분석 상태 | 동일 건의 파이프라인·검토 컬럼 뷰 | **작업·분석 → 진행·검토** |
| 실패 건 | 동일 건의 status=failed + 재실행 | **작업·분석 → 실패** |
| 인력 비교 | 카드 2장 비교는 공간 낭비 | **기술자 → 비교** (직종 필터 표) |
| 직종별 분석 | 카드만 있으면 빈약 | **기술자 → 직종** (인력+영상+비교 링크) |
| 기술자 목록 | 유지 | **기술자 → 목록** |
| 운영 현황 | 명칭·역할 모호 | **대시보드** (KPI·우선처리·최근영상) |
| 업무 프로세스 | 시연 여정 가이드 | **삭제** |
| 시연 흐름 1~5 | 데모 전용 | **사이드바에서 삭제** |

## 클릭 구조

```text
사이드바(상위)          본문 탭(하위)
대시보드          →    (탭 없음, KPI가 하위 화면으로 링크)
작업·분석         →    전체 영상 | 진행·검토 | 실패
기술자            →    목록 | 직종 | 비교

분석 결과(/analysis/[id]) 본문 탭
  종합 | 자세 | 결과물 | 검토  → 평가서(/reports/[id])
```

## 왜 처음에 비어 보였는가

메뉴 IA만 정리하고 **분석·Pose·평가서** 같은 핵심 콘텐츠를 덜어내서입니다.
필수 화면은 아래입니다.

| 화면 | 역할 |
|------|------|
| 대시보드 | 오늘 할 일 · KPI · 최근 건 |
| 작업·분석 | 영상 등록(업로드 팝업) · 진행 · 실패 |
| 기술자 | 목록 · 직종 드릴다운 · 표 비교 |
| 분석 결과 | Explain · 타임라인 · 점수 · 장면 |
| 자세 / 결과물 / 검토 | 근거 확인 · 승인 |
| 평가서 | PDF/CSV용 확정 출력 |
