유알커넥션

금형조립, 영상으로 볼 수 있는
표준 작업 흐름을 만듭니다

NCS(24v4)에서 능력단위요소와 수행준거를 가져와 뼈대를 잡고, 현장 SOP와 숙련 작업 영상으로 실제 순서를 채운 뒤, AI가 비교할 수 있는 단계·시간·행동 단위로 쪼갭니다.

이 자료에서 볼 것 표준 작업 프로세스와 숙련도 평가 기준을 어떻게 잡는지 — NCS에서 이미 확정된 것, 현장에서 더 채워야 할 것, 그다음 할 일.

02

WHY

NCS 이름만 적으면 끝나는 일이 아닙니다

필요한 건 목록이 아니라, 금형조립을 영상에서 따라갈 수 있는 작업 흐름으로 정의하는 일입니다.

목록 ≠ 프로세스

이렇게 하면 안 됨

NCS에 표준 순서가 이미 다 들어 있다

실제로는

NCS로 평가 기준을 잡고, SOP로 현장 순서를 잡고, 숙련 작업 여러 건과 전문가 검토로 “정상 흐름”을 확정한다

부족함

NCS 인용만

  • 능력단위·요소 이름만 정리
  • 지식·기술·태도 문구만 나열
  • 영상에서 잡을 순서가 없음
  • AI 지표·숙련도로 이어지지 않음
필요한 것

표준 작업 프로세스

  • 원문에서 수행준거를 뽑음
  • 영상으로 볼 수 있는 항목만 고름
  • 현장 세부 작업을 단계로 고정
  • AI 지표 → 숙련도까지 연결
기준 수행준거 중에서 작업 중 눈으로 확인할 수 있는 것만 영상 분석에 넣습니다. 영상만으로 판단하기 어려운 지식·판단은 빼거나 별도 항목으로 둡니다.

06

SEQUENCE

영상을 표준 시퀀스에 맞춰 비교합니다

AI는 “숙련도 점수”만 던지지 않습니다. 표준 시퀀스와 맞춰 순서·시간·반복·누락·공구를 봅니다. 세부 코드는 SOP 붙인 뒤 확정합니다.

평가가 말하는 것 표준 대비 순서, 단계별 시간, 반복·재작업, 누락, 공구, 정확도를 보고 숙련도를 판단합니다.

표준은 NCS·SOP를 바탕으로 숙련 작업 여러 건을 보고, 현장 전문가가 검토해 확정합니다. 숙련자 한 명 영상이 곧 정답은 아닙니다.
