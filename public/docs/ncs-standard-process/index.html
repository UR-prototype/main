PROCESS DEFINITION BRIEF · 2026

유알커넥션

NCS와 현장 데이터를 기반으로
금형조립 표준 작업 프로세스를 정의합니다

NCS의 능력단위·수행준거를 기준으로 실제 현장 SOP와 숙련자 작업 영상을 결합하여 표준 작업 시퀀스를 정의하고, 이를 AI가 분석 가능한 행동·순서·시간 단위로 구체화합니다.

문서 목적 「금형조립 표준 작업 프로세스 및 숙련도 평가 기준서」 수립을 위한 접근 방향, 필요 자료, 실행 순서를 공유드립니다.
대상 · 단순 사출금형 조립 (NCS 1510010411_18v3) 근거 · NCS + 현장 SOP + 숙련자 영상 산출 · 표준 작업 시퀀스 · AI 지표 · 숙련도 평가
02

APPROACH

표준 작업 프로세스 정의가 필요한 이유

본 과제의 핵심은 NCS 항목을 나열하는 것이 아니라, 금형조립 작업을 영상 분석이 가능한 표준 작업 프로세스로 정의하는 데 있습니다.

인용을 넘어 정의

적용하지 않는 해석

NCS가 표준 작업 시퀀스를 그대로 제공한다

본 과제의 해석

NCS로 평가의 객관적 기준을 잡고, 현장 SOP로 실제 작업 순서를 정의하며, 숙련자 영상으로 정상 수행 패턴을 확보한다

제한적인 접근

NCS 항목 인용

  • 능력단위·요소 목록 정리에 그침
  • 지식·기술·태도 문구 나열
  • 영상에서 식별할 작업 순서가 부재
  • AI 지표·숙련도 평가로 연결되지 않음
필요한 접근

표준 작업 프로세스 정의

  • 관찰 가능한 수행준거를 선별
  • 현장 세부 작업을 단계열로 고정
  • 영상 분석 가능 흐름으로 구체화
  • AI 지표 → 숙련도 평가까지 연결
적용 원칙 NCS 수행준거 중 작업 과정에서 관찰 가능한 항목을 선별하여 영상 분석 기준으로 구체화합니다. 영상만으로 직접 판별하기 어려운 지식·판단 영역은 영상 기반 숙련도 평가에서 제외하거나 별도 평가항목으로 구분합니다.

04

EVIDENCE BASE

NCS와 현장자료를 함께 확보합니다

NCS는 「무엇을 할 수 있어야 하는가」를, 현장자료(SOP·도면·영상·평가표 등)는 「실제로 어떤 순서로 수행하는가」를 제공합니다. 표준 작업 시퀀스는 이 근거 자료의 결합으로 완성됩니다.

능력단위에서 AI 지표까지 계층을 내려가며 표준 작업 시퀀스를 산출합니다.

L1 → L5

Level정의예시
L1 능력단위 NCS 작업 범위 단순 사출금형 조립
L2 능력단위요소 주요 수행 단계 고정측 조립하기
L3 표준작업 현장 SOP 세부절차 부품 배치 → 체결 → 확인
L4 관찰행동 영상 인식 단위 부품 집기 → 위치 이동 → 공구 체결

NCS→ 능력단위요소→ 현장 세부작업→ 영상 관찰행동→ AI 지표→ 숙련도

06

STANDARD SEQUENCE · COMPARISON

표준 시퀀스와 영상 비교

AI는 작업 영상을 표준 시퀀스(Standard Sequence)와 비교하여 순서·시간·반복·누락·공구 사용을 분석합니다.

평가 정의 표준 작업 프로세스 대비 작업 순서, 단계별 소요시간, 반복·재작업, 누락, 공구 사용 및 작업 정확도를 분석하여 숙련도를 평가합니다.

표준 시퀀스는 NCS·SOP를 기준으로 숙련 작업 사례를 분석하고 현장 전문가 검토를 거쳐 확정합니다. 숙련자 1명의 행동이 곧 표준이 되지는 않습니다.

07

EXECUTION PLAN

실행 계획 및 자료 요청

NCS 자료 검토와 함께, 실제 작업 시퀀스 정의를 위한 현장자료 확보가 우선 필요합니다. 확보 후 아래 순서로 기준서를 완성합니다.

전달 메시지

NCS가 표준 작업 시퀀스를 그대로 제공하지는 않습니다. NCS로 평가 기준을 잡고, 현장 SOP로 실제 순서를 정의하며, 복수의 숙련 작업 사례와 전문가 검토로 정상 수행 패턴을 확정하는 구조로 표준 작업 프로세스를 완성합니다.
